# E-Commerce SQL Analytics Project

## Project Objective

The objective of this project is to perform end-to-end business analysis on an e-commerce dataset using SQL. The project focuses on uncovering insights related to customer behavior, sales performance, revenue trends, product analysis, and operational efficiency through structured analytical querying.

---

## Tools Used

* SQL (SQLite)
* Python
* Pandas
* Google Colab
* GitHub

---

## SQL Concepts Covered

* Data Exploration
* Data Cleaning & Validation
* Joins (Inner Joins & Multi-table Joins)
* Aggregations & Grouping
* CASE WHEN Statements
* Common Table Expressions (CTEs)
* Window Functions
* Ranking Functions
* Running Totals
* Business KPI Analysis
* Customer & Revenue Analytics

---

## Dataset Source

Brazilian E-Commerce Public Dataset by Olist available on Kaggle.

Dataset includes:

* Orders
* Customers
* Products
* Payments
* Order Items
* Reviews
* Delivery Information

---

## Key Business Insights

* Identified high-performing states contributing maximum revenue.
* Analyzed monthly revenue trends and overall sales growth patterns.
* Performed customer segmentation based on spending behavior.
* Identified top-performing product categories and products.
* Evaluated delivery performance and operational efficiency.
* Used advanced SQL techniques such as CTEs and window functions for analytical reporting.

---

## Conclusion

This project demonstrates the practical application of SQL for solving real-world business problems in the e-commerce domain. It highlights analytical thinking, data exploration, KPI generation, and advanced querying techniques commonly used in Data Analyst and Business Intelligence roles.
